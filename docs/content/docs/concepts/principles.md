## Claims are hypotheses

Vendor documentation can describe intended behavior. It cannot substitute for
observed behavior.

## Change one variable

A counterfactual experiment compares a baseline and treatment run that differ
in exactly one declared persona value. Uncontrolled differences weaken the
conclusion and must be reported.

## Preserve the path to evidence

Every finding must identify the observations that support it, the
normalizations applied to them, and any capture gaps.

## Minimize collection

Ariadne should collect only what a declared experiment requires. Secrets and
unrelated personal data are redacted by default.

## Say what is unknown

Missing visibility is not evidence that nothing happened.
